# סורק מסמכי בתי הדין הרבניים

> **תוסף Chrome** שמוריד אוטומטית את כל המסמכים מכל התיקים שלך באתר בתי הדין הרבניים, ממיין אותם לתיקיות לפי סוג, ונותן לכל קובץ שם ברור: תאריך, סוג המסמך, הכותרת, ומי הגיש.
>
> *English: a Chrome extension that bulk-downloads, classifies and renames the documents of your own cases on the Israeli Rabbinical Courts site (`sides.rbc.gov.il`). Runs fully locally, no cloud, no LLM.*

---

## מה זה עושה

במקום ללחוץ על מאות מסמכים אחד-אחד, התוסף:

1. **מאתר את כל התיקים שלך** – פתוחים **וסגורים**, כולל כל תיקי המשנה.
2. **נותן לך לבחור** אילו תיקים להוריד (ויכול לסרוק מראש ולהראות כמה מסמכים יש בכל תיק).
3. **מוריד את כל המסמכים** מלשונית "מסמכים" של כל תיק נבחר.
4. **ממיין ומשנה שמות** לפי המידע באתר ותוכן המסמך עצמו – החלטות, הזמנות לדיון, בקשות וכתבי טענות, פרוטוקולים, נספחים, פעולות מנהליות.
5. **קורא גם מסמכים סרוקים** (תמונות PDF) באמצעות זיהוי טקסט (OCR) בעברית – ללא אינטרנט וללא שירות חיצוני.
6. **מוציא קובץ ZIP לכל תיק ראשי**, עם אינדקס (`index.csv` שנפתח באקסל בעברית, ו-`index.json`) שמפרט כל מסמך.

### דוגמה לשמות הקבצים

```
2222222.zip
└── 2222222/
    ├── index.csv   index.json
    └── 2222222-15 - חלוקת רכוש - כריכה/
        ├── החלטות/             2024-01-16_החלטה_החזרת פיקדונות_בית הדין.docx
        ├── בקשות וכתבי טענות/   2024-01-10_בקשה להחזר ערובה_גולן רן.pdf
        ├── הזמנות לדיון/        2023-08-29_הזמנה לביה״ד_עבור שרה ישראלי_דיון 2024-01-22_בית הדין.docx
        ├── נספחים/              2023-07-04_נספח לתגובה 1_כהן דן.pdf
        └── פעולות מנהליות/      2023-09-14_יפוי כח_שגיא עומר.pdf
```

שם הקובץ בנוי כך: **תאריך קבלה ← סוג ← כותרת ← (נמען / תאריך דיון) ← מגיש (ותפקידו, כשזוהה)**.
הכותרת היא נושא המסמך כפי שמופיע באתר (למשל "בקשה לדחיית מועד דיון" או "הבהרה בבקשה ל…"), ובהיעדרה היא נלקחת מגוף המסמך.

> השמות והמספרים בדוגמה פיקטיביים.

## התחלה מהירה (כ-3 דקות)

### אפשרות א׳ – הורדה מוכנה (מומלץ)

1. היכנס ל-[**Releases**](../../releases/latest) והורד את הקובץ `rbc-case-scraper-extension.zip`.
2. פתח את ה-ZIP לתיקייה קבועה (למשל `C:\Tools\rbc-scraper`) – **אל תמחק אותה**, Chrome קורא את התוסף משם.
3. ב-Chrome פתח `chrome://extensions`, הפעל **Developer mode** (מצב מפתח, בפינה העליונה), ולחץ **Load unpacked** (טעינת תוסף שאינו ארוז) ובחר את התיקייה.

### אפשרות ב׳ – בנייה מהקוד

```bash
git clone https://github.com/giladra/rbc-case-scraper.git
cd rbc-case-scraper
npm install
npm run build
```

ואז, באותו אופן, טען ב-`chrome://extensions` את התיקייה `dist`. (דרוש Node.js 20 ומעלה.)

## שימוש

1. היכנס לאתר בתי הדין כרגיל (הזדהות ממשלתית) ועבור לעמוד **התיקים שלי**.
2. בפינה השמאלית העליונה יופיע חלון **"סורק מסמכי בתי הדין"**.
3. לחץ **טען תיקים (פתוחים וסגורים)** – תופיע רשימת התיקים ותיקי המשנה, הכל מסומן כברירת מחדל. הסר סימון ממה שלא צריך.
4. *(אופציונלי)* **סרוק מסמכים** – מציג כמה מסמכים יש בכל תיק משנה ומסיר תיקים ריקים.
5. לחץ **הורד נבחרים**. קובץ ZIP יישמר אוטומטית ברגע שכל תיק ראשי מסתיים. אפשר ללחוץ **עצור** בכל שלב ולקבל ZIP חלקי.

תיבת הסימון **OCR** שולטת בקריאת מסמכים סרוקים. כבוי = מהיר יותר, אבל מסמכים סרוקים ימוינו רק לפי המידע שהאתר נותן.

> ⏱️ קצב: כשנייה עד שלוש לכל מסמך סרוק. תיק עם כ-300 מסמכים לוקח כ-8 דקות. השאר את הלשונית פתוחה עד הסיום.

## הערות באינדקס

בעמודת "הערות" ב-`index.csv` תופיע לכל מסמך אינדיקציה לאיכות הזיהוי:

| הערה | משמעות |
|---|---|
| `ocr` | מסמך סרוק שנקרא בהצלחה בזיהוי טקסט. הטקסט משמש להשלמת כותרת ותפקיד המגיש – **לעולם לא** לסיווג או לתאריכים (ספרות ב-OCR לא אמינות). |
| `ocr-low-confidence` | הסריקה לא ברורה; התעלמנו מהטקסט והסתמכנו על מידע האתר בלבד. |
| `needs-ocr` | מסמך סרוק שלא נקרא (OCR כבוי או נכשל). |
| `headline-from-body` / `no-headline` | האתר לא נתן כותרת; נלקחה מגוף המסמך, או שיש רק סוג כללי. |
| `type-mismatch` | סוג המסמך באתר ובכותרת המסמך סותרים (הסיווג נקבע לפי האתר). |
| `download-failed: …` | ההורדה נכשלה (למשל האתר מחזיר קובץ ריק). השורה נשארת באינדקס. |
| `extract-failed: …` | לא ניתן היה לקרוא את הקובץ; ההודעה מסבירה למה. |

## פרטיות ואבטחה

- **הכל רץ מקומית בדפדפן שלך.** אין שרת, אין ענן, אין שירות AI וללא איסוף נתונים. התוסף פונה רק לאתר בתי הדין, בתוך ההתחברות הקיימת שלך.
- התוסף **לא שומר ולא מזין סיסמאות**; הוא משתמש בחיבור שכבר פתחת.
- המסמכים נשמרים רק כקבצי ZIP בתיקיית ההורדות שלך.
- הרשאת האתר היחידה: `sides.rbc.gov.il/Pages/FilesList.aspx`.

## מגבלות

- זיהוי הטקסט (OCR) הוא בעברית בלבד, ורק בעמוד הראשון של מסמך סרוק; סריקות באיכות נמוכה לא יקראו.
- התוסף נשען על מבנה האתר הנוכחי. אם האתר ישתנה, ייתכן שיידרש עדכון.
- תיק שבו האתר מחזיר מסמך ריק – ירשם באינדקס כנכשל.
- התוסף נבדק על חשבון אמיתי אחד; ייתכנו סוגי מסמכים שעדיין לא מסווגים (הם ינחתו בתיקיית "לא מסווג" עם הערה).

## הצהרת אחריות

פרויקט עצמאי, **ללא קשר לבתי הדין הרבניים או למערכת בתי הדין**. מיועד לשימוש במסמכי התיקים **שלך** בלבד, דרך חשבונך. השימוש באחריותך. בדוק שהוא תואם את תנאי השימוש של האתר.

## לפיתוח

```bash
npm test                          # בדיקות יחידה (vitest)
npm run build                     # בונה את התיקייה dist/
node tools/serve-dist.mjs         # בטרמינל נפרד: שרת מקומי לבדיקת התוסף
node tools/ext-test.mjs           # טוען את התוסף ל-Chromium ובודק את נתיב ה-OCR האמיתי
```

מבנה: `src/site` (תקשורת עם האתר), `src/analysis` (סיווג, חילוץ טקסט), `src/ocr` (דף OCR בתוך התוסף), `src/output` (שמות, אינדקס, ZIP), `src/run` (התזמור), `src/content` (הממשק).
המסמכים האמיתיים שלך (אם תרצה לפתח כללי סיווג) יש לשמור רק בתיקייה `fixtures-private/` שאינה נכנסת ל-git.
